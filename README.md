# Gautami Kharwar · Portfolio

Personal portfolio of Gautami Kharwar, Senior Product Designer for AI products and e-commerce.

**Live site:** https://workgautami2813-del.github.io/Gautami-Portfolio/

It is a single static page (`index.html`) with no build step: the home page plus three case studies
(Apycue AI-agent platform, hotel website templates, 60+ e-commerce stores) shown by URL hash
(`#apycue`, `#hotel-templates`, `#ecommerce`).

## Run locally
Open `index.html` in a browser.
